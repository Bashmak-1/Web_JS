# Лабораторний проект: "Фільмова база"

## Опис проекту
"Фільмова база" — це односторінковий веб-застосунок (SPA), який отримує дані про серіали та фільми за допомогою TV Maze API та відображає їх у вигляді зручних карток. Користувач має змогу шукати фільми за назвою та сортувати їх за рейтингом або алфавітом.

## Логічна схема застосунку (План)
1. **Ініціалізація:** При завантаженні сторінки викликається асинхронна функція `fetchMovies()`.
2. **Отримання даних (Fetch API):** Робиться GET-запит до `https://api.tvmaze.com/shows`. Використовується конструкція `try/catch` для перехоплення помилок мережі або неправильних статус-кодів.
3. **Збереження стану:** Отриманий масив об'єктів зберігається у глобальну змінну `allMovies`. Це дозволяє виконувати пошук і сортування миттєво на стороні клієнта без повторних запитів до сервера.
4. **Рендеринг (DOM Manipulation):** Функція `renderMovies()` приймає масив фільмів. За допомогою методу `.map()` та *ES6 деструктуризації* формується HTML-розмітка (через *шаблонні рядки*), яка вставляється у контейнер `#movies`.
5. **Фільтрація та сортування:** При введенні тексту в поле пошуку (`input`) або зміні опції сортування (`change`) викликається функція `handleFilterAndSort()`. Вона створює відфільтровану копію масиву і сортує його за допомогою методу `.sort()`, після чого знову викликає `renderMovies()`.

## Використані технології та синтаксис
* **HTML/CSS:** Grid-розкладка (CSS Grid) для адаптивного відображення карток.
* **JavaScript (ES6+):** 
  * `async/await` для асинхронних запитів.
  * `"use strict"` для суворого режиму.
  * Стрілочні функції `const renderMovies = () => {}`.
  * Шаблонні рядки `` `<h1>${title}</h1>` ``.
  * Деструктуризація об'єктів `const { name, rating } = movie;`.
  * Опціональний ланцюжок (Optional Chaining) `image?.medium` для уникнення помилок, якщо у фільму немає картинки.

## Обробка помилок
Якщо API недоступне, застосунок перехоплює помилку в блоці `catch`, ховає індикатор завантаження та виводить червоне повідомлення у контейнер `#error-container` на сторінці, інформуючи користувача про проблему.

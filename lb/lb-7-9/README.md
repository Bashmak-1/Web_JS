# 🎮 React Clicker Game

Повноцінна гра-клікер, створена за допомогою React + Vite.

## 🛠 Технології
- React + Vite
- SCSS Modules (Ізольована стилізація)
- `idb-keyval` (Збереження прогресу в IndexedDB)

## 🎯 Функціонал
1. **Клік-механіка:** Заробіток кредитів за допомогою кліків або натискання клавіші `Space`.
2. **Апгрейди:** 5 типів покращень з динамічним зростанням ціни.
3. **Антибонуси (Випадкові події):** 
   - *DDoS:* блокує кліки на 10 секунд.
   - *Bug:* зупиняє пасивний дохід на 10 секунд.
   - *Virus:* миттєво віднімає 10% балансу.
4. **Престиж:** Можливість обміняти 10,000+ кредитів на `Duiktcoins`, які дають +10% до всього доходу (Hard Reset прогресу).
5. **Скіни:** Можливість купувати та перемикати візуальні теми гри.
6. **Збереження:** Автоматичне збереження гри в IndexedDB кожні 5 секунд та при закритті вкладки.

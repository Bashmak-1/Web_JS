# Навчальний Архів з JavaScript (Web_JS) 🎓

Цей репозиторій створений для збереження та організації практичних і лабораторних робіт з курсу **JavaScript (Web)** в університеті. Проект є зручним порталом для демонстрації виконаних завдань викладачеві.

---

## 🖥️ Головний Портал (`index.html`)

У корені репозиторію знаходиться інтерактивна веб-сторінка, яка об'єднує всі виконані роботи. Вона має сучасний, адаптивний інтерфейс з картками для швидкого переходу до кожної конкретної роботи.

---

## 📁 Структура Проекту

Проект має чітку та структуровану ієрархію:

```text
Web_JS/
├── lb/                    # Лабораторні роботи (Laboratory Works)
│   ├── lb-1-3/            # Конструктор резюме
│   ├── lb-4-6/            # Фільмова база
│   └── lb-7-9/            # Clicker Game (зібраний дистрибутив у dist)
├── pr/                    # Практичні роботи (Practical Works)
│   ├── pr1/               # Анкета
│   ├── pr2/               # Функції та замикання
│   ├── pr3/               # ООП (Об'єктно-орієнтоване програмування)
│   ├── pr4/               # To-Do List (Список завдань)
│   ├── pr5/               # PokeAPI (Робота з зовнішнім API)
│   ├── pr6/               # ES6+ Модулі
│   └── pr7/               # Робота з даними
├── index.html             # Головний портал-навігатор
├── script.js              # Інтерактивна логіка порталу
├── style.css              # Стилі оформлення порталу
└── .gitignore             # Налаштування виключень Git (ігнорує тимчасові та .txt файли)
```

---

## 🚀 Як запустити проект локально

1. Склонуйте цей репозиторій на свій комп'ютер:

   ```bash
   git clone <URL_репозиторію>
   ```

2. Відкрийте кореневий файл `index.html` у будь-якому сучасному браузері.
3. Використовуйте зручну навігаційну панель для переходу до практичних (`pr`) та лабораторних (`lb`) робіт.
